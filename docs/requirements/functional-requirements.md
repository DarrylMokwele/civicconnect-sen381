# CivicConnect Functional Requirements

## Requester Requirements

| ID | Requirement | Source | Priority |
|---|---|---|---|
| FR-001 | The system shall allow a requester to submit a service request with the required information. | STK-001 | Must |
| FR-002 | The system shall allow a requester to select a category for a service request. | STK-001 | Must |
| FR-003 | The system shall allow a requester to view the current status of their requests. | STK-001 | Must |
| FR-004 | The system shall allow a requester to view their previous requests. | STK-001 | Must |
| FR-005 | The system shall give the requester feedback when a request is submitted, rejected, updated or completed. | STK-001 | Must |

## Operational Staff Requirements

| ID | Requirement | Source | Priority |
|---|---|---|---|
| FR-006 | The system shall allow authorised staff to view requests relevant to them. | STK-002 | Must |
| FR-007 | The system shall allow authorised staff to search, filter and sort requests. | STK-002 | Must |
| FR-008 | The system shall allow authorised staff to view the details of a request. | STK-002 | Must |
| FR-009 | The system shall allow authorised staff to take or be assigned responsibility for a request. | STK-002 | Must |
| FR-010 | The system shall allow authorised staff to update a request's status using allowed status changes. | STK-002 | Must |
| FR-011 | The system shall allow authorised staff to record actions, comments or resolution details on a request. | STK-002 | Must |
| FR-012 | The system shall allow authorised staff to resolve or close a request. | STK-002 | Must |

## Management Requirements

| ID | Requirement | Source | Priority |
|---|---|---|---|
| FR-013 | The system shall allow authorised management users to view service request activity. | STK-003 | Must |
| FR-014 | The system shall allow management to identify open, overdue, resolved and closed requests. | STK-003 | Must |
| FR-015 | The system shall allow management to view request information by category and status. | STK-003 | Must |
| FR-016 | The system shall provide information that management can use to check service performance and accountability. | STK-003 | Must |
